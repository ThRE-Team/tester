# Debian Trixie Package Checker

Repo ini gak penting, hanya buat cek-cek versi paket di Debian Trixie pake GitHub Actions.

## Cara Pake:
1. Masuk ke tab **Actions**.
2. Pilih **Debian Package Checker**.
3. Klik **Run workflow**, ketik nama paket yang mau dicek (pisahin pake spasi).
4. Tinggal liat log hasilnya.
